README to Bookmarks Converter

Markdown dosyalarınızı tarayıcı yer imleri formatına dönüştürün

Proje Amacı

Bu araç, markdown formatındaki README dosyalarınızı tarayıcılarda kullanılabilir yer imleri (bookmarks) formatına dönüştürür. Özellikle free-for-dev gibi büyük projelerdeki linkleri kolayca yer imlerinize ekleyebilirsiniz.

Özellikler:

  • Markdown dosyalarını otomatik olarak ayrıştırır
  • Başlıkları kategori olarak kullanır
  • Linkleri yer imlerine dönüştürür
  • Oluşturulan HTML dosyasını yerel klasöre kaydedilebilir hale getirir
  • Tamamen responsive tasarım

Dönüştürme Aracı

İpucu: Yerel dosya seçerseniz, üstteki seçim yerine bu dosya işlenecektir.
